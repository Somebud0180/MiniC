# Mini C
### A C/C++ IDE in your pocket

Mini C is a C/C++ IDE made for iOS and iPadOS. Featuring a simplified IDE that lets you code and run your programs with ease.

### Features
- Offline C99 compilation and execution with bundled Clang
- Offline C++11 compilation and execution with bundled Clang and libc++ (exceptions unsupported)
- Simple Coding Interface
- Quick Keys
- Smart Code Structuring
- Prettify
- Autosave
- Interactive Terminal

## Offline compiler

Mini C compiles the current source file with bundled Clang in C99 or C++11 mode (`-std=c99` / `-std=c++11`, with `-pedantic-errors`), links against the bundled WASI C library and libc++ for C++, and runs the resulting WebAssembly program offline. Local quoted headers are supported; additional source files are not automatically compiled or linked.

This provides C99 and C++11 language support within the bundled toolchain and runtime. C++ exceptions are disabled. Programs use the 32-bit WebAssembly/WASI target and receive terminal input and output, with no host directories exposed and no networking or multithreading support. Desktop- or platform-specific libraries and APIs are not generally available.

The terminal supports interactive input, EOF, Stop, and rerun. Runs are bounded by an execution fuel budget, 64 MiB of linear memory, a 1 MiB stack, 256 KiB of output, and 64 KiB of input; source files are limited to 256 KiB.

The bundled compiler supports physical iOS devices and Intel iOS simulators. ARM iOS simulators can run bundled WebAssembly examples but cannot compile source with the current compiler slices.
